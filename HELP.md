# Help & Resources

This project is a Spring Boot application. Below are some useful resources for development and troubleshooting.

## Useful Links
* [Spring Boot Reference Guide](https://docs.spring.io/spring-boot/docs/current/reference/htmlsingle/)
* [Spring Data JPA Documentation](https://docs.spring.io/spring-data/jpa/docs/current/reference/html/)
* [H2 Database Console](http://localhost:8080/h2-console) (Requires app to be running)

## Common Commands
* `./mvnw clean install` - Build the project and install to local repo.
* `./mvnw test` - Run all integration tests.
* `./mvnw spring-boot:run` - Start the application locally.

## Project Structure
* `src/main/java` - Core application logic.
* `src/test/java` - Integration and unit tests.
* `src/main/resources` - Configuration and database settings.
